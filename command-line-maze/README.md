The Lost Octane Track

Aashi Agarwal

Welcome to my awesome Don Toliver inspired command line maze.

A set of unreleased tracks has been lost somewhere in the mace. Start in the entrance folder and follow clues until you find it.

Helpful Commands

ls - view files and folders
ls -a - view hidden files
cd folder-name - enter a folder
cd .. - go back one folder
cat filename.txt - read a file
pwd - see your current location

Good Luck!!!
